## push-back-vex

This is the code for the VEX V5 Team 1965M for the 2025-2026 VEX competition, push-back.

This is built using the Pros Framework, using the EZ-Template Library.

The Chrome Extension was built to enhance the process of copying autonomous movements from the website [path.jerryio.com](path.jerryio.com) and the codebase.
